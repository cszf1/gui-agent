修复 v0.9.0 在部分 Windows 电脑上打开后只显示黑色背景的问题。

此前本地服务使用 Python 的系统 MIME 映射；如果其他软件将 `.js` 映射成 `text/plain`，Edge 会拒绝执行前端模块。v0.9.1 为程序自己的 JS、CSS、HTML、图片、字体等资源固定响应类型，不再读取系统文件类型映射，也不修改系统注册表。`nosniff`、CSP、文件路径保护与本地 API 认证保持有效。

HTTP 回归测试模拟错误 MIME 映射；浏览器端验证 JS/CSS 响应类型、界面显示、设置打开、新对话及完整执行流程。Windows CI 使用安装载荷中的嵌入式 Python 和真实系统 Edge 完成相同验证，并检查原生 UIA、实际启动器、升级、卸载和便携模式，再上传附件。

Windows x64 精简安装版与便携版仍使用系统 Edge，不需要额外安装 Python、Node.js 或 Chromium。关闭旧版后直接运行安装包，升级保留密钥、设置和历史；便携版可将旧版 data 目录移到新版旁边。实际体积和 SHA256 见附件 build-manifest.json。

模型服务仍需自行填写 Base URL、API Key 和模型名称。安装包尚未签名。
