Windows x64 精简版：系统 Edge 打开界面，官方嵌入式 Python 运行引擎。最终用户不需要额外安装 Python、Node.js 或 Chromium。

- 控件名称与类型唯一匹配时直接定位；视觉坐标命中控件时绑定原节点，执行前检查身份，避免界面移动后点击错误控件。
- UIA Invoke、Toggle、Select、Focus 移除默认固定等待；明确后置条件立即核验，未生效时继续等待。已经发出的非幂等动作不会自动重放。
- 桌面模式开启 Set-of-Mark 与视觉定位复核，拒绝低置信度定位。安全确认、暂停和急停继续保留。
- 去掉 NumPy，Pillow 像素差分与原实现等价；锁定 Windows 依赖，仅裁剪桌面发布内容，保留源码仓库的跨平台、MCP、沙盒和评测能力。
- 提供单用户安装版和便携 ZIP，默认不创建桌面快捷方式。安装版只写一个 HKCU 卸载键；便携版数据在旁边的 data 目录。
- 卸载先验证归属并移除链接，再按安装文件清单删除，保留用户另放的文件。截图默认不保存，历史容量限制、临时缓存清理和崩溃进程树清理继续保留。

安装版升级保留密钥、设置和历史；卸载删除本软件用户数据。Windows CI 在发布附件前验证实际启动器、Edge 界面、嵌入式 UIA、DPAPI、升级、崩溃恢复、卸载及便携模式。build-manifest.json 提供实际字节数及依赖清单。

这些验证使用确定的测试策略，不代表真实模型的任务成功率或端到端速度排名。明确控件定位无需额外模型调用，纯视觉放大复核会增加一次定位请求。Base URL、API Key 和模型名称仍由用户自行配置；需要系统安装 Microsoft Edge。
